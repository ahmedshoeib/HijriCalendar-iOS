# Changelog

All notable changes will be documented in this file. This project follows Semantic Versioning.

## 1.0.0 - 2026-09-28

- Add a Foundation date engine supporting Umm al-Qura, Islamic, Civil, and Tabular systems with a six-week month grid.
- Add single, multiple, range, and read-only selection modes.
- Add the UIKit calendar view, delegates, day decorations, RTL, and accessibility.
- Add the SwiftUI binding interface, styling, and event modifiers.
- Add explicit runtime locale, time-zone, and LTR/RTL direction configuration.
- Add clamped manual day adjustment and authority-published month-start overrides with bidirectional conversion.
- Add complete UIKit and SwiftUI Xcode demo applications.
- Add Swift Package Manager products, expanded tests, documentation, and examples.
